# Case Study O15 — Pregnancy Hypertension (FinnGen R9)

Cross-method comparison tables for O15_HYPTENSPREG (FinnGen R9: 14,727 cases / 196,143 controls).
LSEA vs MAGMA (mean + top) vs PASCAL across 6 gene set categories.

## Files

| `O15_HYPTENSPREG_comparison_bcm.tsv` | Blood cell markers | LSEA + MAGMA comparison |

## How to Obtain

Generated by `tests/preprocessing/compile_case_study.py` from LSEA, MAGMA, and PASCAL output.
Full pipeline: `tests/scripts/5_1_case_study_o15.sh`.

## Key Findings

Convergence across all three methods on:
- Hemostasis / coagulation pathways (C2)
- Immune system pathways (C2, GO:BP)
- VEGF signaling (C2)
- Liver / placenta tissue enrichment (GTEx)
