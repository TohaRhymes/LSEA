# LSEA Experiments

This directory contains scripts to reproduce all experiments described in the LSEA paper
("LSEA: Instrument for Fast and Flexible Interval-Based Enrichment Analysis",
Changalidis et al.).

## Data Preparation

See [DATA_PREPARATION.md](DATA_PREPARATION.md) for full details on how input data was generated:
- bioGWAS simulations (pathway selection, simulation parameters, output format)
- Pan-UKB GWAS summary statistics (phenotype selection, download, normalization)
- Reference data (1000G EUR, GENCODE v37, GMT gene sets)

## Prerequisites

- **LSEA** code from this repository
- **PLINK v1.9** (for LD-based clumping)
- **BEDTools** (for interval intersection)
- **Python 3** with dependencies from `requirements.txt`
- **`.env` file** in the repository root with server-specific paths (see `.env.example`)

## Setup

Copy `.env.example` to `.env` and fill in the paths for your server:

```bash
cp .env.example .env
# Edit .env with your paths
```

The `.env` file is in `.gitignore` and will not be pushed.

## Experiments Overview

### I. bioGWAS — TPR/FPR (Scripts 00-02)

LSEA is tested on simulated GWAS data generated by
[bioGWAS](https://github.com/TohaRhymes/GWAS_simulator) to measure True Positive Rate
and False Positive Rate. Results are compared with MAGMA (linreg, mean, top) and PASCAL.

Simulations use N=10,000 individuals with K=30 total causal SNPs:
k=15 SNPs selected from a target pathway + 15 random SNPs.
Genotype data: 1000 Genomes EUR. Gene sets: MSigDB C2 KEGG (186 pathways).

| Script | Experiment | Runs | Description |
|--------|-----------|------|-------------|
| `00_create_universe.sh` | Universe generation | 1 | Create universe JSON (N=59,409 intervals) |
| `01_lsea_continuous.sh` | Continuous traits | 200 (50 iter x 4 pathway sizes) | TPR/FPR on continuous phenotype simulations |
| `02_lsea_binary.sh` | Binary traits | 200 (50 iter x 4 pathway sizes) | TPR/FPR on binary phenotype simulations |

**Target pathways (from MSigDB C2 KEGG):**

| Size | KEGG Pathway | Genes |
|------|-------------|-------|
| `small` | KEGG_STEROID_BIOSYNTHESIS | 17 |
| `medium` | KEGG_PPAR_SIGNALING_PATHWAY | 69 |
| `big` | KEGG_FOCAL_ADHESION | 199 |
| `random` | control (no target pathway) | — |

For `random`, all K=30 causal SNPs are chosen at random (no pathway enrichment expected).

### II. bioGWAS — Sensitivity Analysis (Script 03)

Tests LSEA's ability to detect pathway enrichment when the number of
pathway-associated causal SNPs (k) is small.

| Script | Experiment | Runs | Description |
|--------|-----------|------|-------------|
| `03_lsea_sensitivity.sh` | Sensitivity (k) | 135 (15 k-values x 3 iter x 3 sizes) | Vary k=1..15, total SNPs=30 |

- k ranges from 1 to 15 (remaining 30−k SNPs are random)
- 3 pathway sizes: `small` (17), `medium` (69), `big` (199) — no `random`
- 3 iterations per (k, size) combination
- Uses `--print_all` to output all pathways (including non-significant)
- Theoretical minimum k for significance can be computed from
  hypergeom(k, N=59409, K_big, n=30), where K_big ∈ {17, 69, 199}

### III. Pan-UKB — Enrichment (Scripts 04-05)

LSEA is applied to real GWAS data from the
[Pan-UK Biobank](https://pan.ukbb.broadinstitute.org/) project.
150 phenotypes from the maximal independent set (MIS), corresponding to
139 unique phenotype codes.

| Script | Experiment | Runs | Description |
|--------|-----------|------|-------------|
| `04_panukb_universes.sh` | Universe creation | 6 | One universe per gene set category |
| `05_panukb_enrichment.sh` | Enrichment | 900 (150 pheno x 6 categories) | LSEA on each phenotype x gene set category |

**Gene set categories:**

| Short name | Source | Gene sets | GMT file |
|-----------|--------|-----------|----------|
| `c2` | MSigDB C2 (all curated) | 7,233 | `c2.all.v2023.2.Hs.symbols.gmt` |
| `gte` | GTEx v8 | 45 tissues | `GTEx8_formatted.gmt` |
| `bcm` | Literature | 12 | `blood_cell_markers.gmt` |
| `go_bp` | MSigDB C5 | 7,608 | `c5.go.bp.v2024.1.Hs.symbols.gmt` |
| `go_cc` | MSigDB C5 | 1,026 | `c5.go.cc.v2024.1.Hs.symbols.gmt` |
| `go_mf` | MSigDB C5 | 1,820 | `c5.go.mf.v2024.1.Hs.symbols.gmt` |

### IV. Pan-UKB — GWAS-on-GWAS (Script 06)

Cross-trait enrichment analysis: significant loci from each of the 150 phenotypes
are used as "gene sets", and LSEA tests whether loci for one phenotype are
enriched among loci for another.

| Script | Experiment | Runs | Description |
|--------|-----------|------|-------------|
| `06_panukb_gwas_on_gwas.sh` | GWAS-on-GWAS | 150 | Each phenotype vs all-phenotype universe |

Steps:
1. Collect `merged_with_line_numbers.bed` from Experiment III results
2. Build a universe where each phenotype's loci are a "feature set"
3. Run LSEA with `--print_all` on each phenotype against this universe

## Common Parameters

| Parameter | bioGWAS value | Pan-UKB value | Description |
|-----------|--------------|---------------|-------------|
| `--clump_p1` | 7.2973e-9 (Bonferroni) | 7.479e-9 (0.05/6,685,228) | Bonferroni p-value threshold |
| `--clump_p2` | 0.01 (default) | 0.01 (default) | Secondary clumping threshold |
| `--clump_r2` | 0.1 (default) | 0.1 (default) | LD r² threshold |
| `--clump_kb` | 500 (default) | 500 (default) | Physical distance for clumping (kb) |
| Interval | 500,000 bp | 500,000 bp | Universe interval size |
| LD ref panel | simulated genotypes | 1000G EUR | PLINK bfile for clumping |
| Gene sets | C2 KEGG (186 sets) | 6 categories (see above) | GMT file(s) used |

**Pan-UKB GWAS preprocessing:**

Pan-UKB summary statistics have `neglog10_pval_EUR` instead of p-values
and need normalization before LSEA. Use `preproc_tsv.py`:

```bash
python3 experiments/preproc_tsv.py INPUT.tsv.tsv OUTPUT.norm.tsv BFILE.bim
```

**Utility scripts:**

| Script | Description |
|--------|-------------|
| `preproc_tsv.py` | Normalize Pan-UKB GWAS summary statistics |
| `compare_results.py` | Compare annotation_stats between old and new results |
| `validate_single_runs.sh` | Run one test per experiment type and compare with existing results |
| `rerun_all_biogwas.sh` | Full re-run of all 535 bioGWAS experiments |
| `rerun_all_panukb.sh` | Full re-run of all Pan-UKB experiments (Parts 1-3) |

## How to Reproduce

1. **Set up `.env`** with your server paths (see `.env.example`)
2. **Run scripts in order** — universe scripts must complete before analysis:
   - bioGWAS: `00` → `01`, `02`, `03`
   - Pan-UKB: `04` → `05` → `06`
3. **Check results** against `../results/` directory

```bash
# bioGWAS pipeline
bash experiments/00_create_universe.sh
bash experiments/01_lsea_continuous.sh   # ~hours for 200 runs
bash experiments/02_lsea_binary.sh       # ~hours for 200 runs
bash experiments/03_lsea_sensitivity.sh  # ~hours for 135 runs

# Pan-UKB pipeline
bash experiments/04_panukb_universes.sh        # ~1h for 6 universes
bash experiments/05_panukb_enrichment.sh       # ~15h for 900 runs
bash experiments/06_panukb_gwas_on_gwas.sh     # ~3h for 150 runs
```

## CLI Flag Reference

Old scripts used single-dash flags (e.g., `-input`, `-variants`).
Current LSEA uses standard `--long_flag` format. All scripts in this directory
use updated `--` flags. See mapping:

| Old flag | New flag | Short flag |
|----------|----------|------------|
| `-variants` | `--variants` | `-v` |
| `-features` | `--features` | `-ft` |
| `-interval` | `--interval` | `-i` |
| `-input` | `--input` | `-i` |
| `-universe` | `--universe` | `-u` |
| `-out` | `--out` | `-o` |
| `-plink_dir` | `--plink_dir` | `-pd` |
| `-bfile` | `--bfile` | `-bf` |
| `-column_names` | `--column_names` | `-cols` |
| `-p` | `--clump_p1` | `-c_p` |
