# LSEA Experiments

This directory contains scripts to reproduce all experiments described in the LSEA paper.

## Prerequisites

- **LSEA** code from this repository
- **PLINK v1.9** (for LD-based clumping)
- **BEDTools** (for interval intersection)
- **Python 3** with dependencies from `requirements.txt`
- **`.env` file** in the repository root with server-specific paths (see `.env.example`)

## Setup

Copy `.env.example` to `.env` and fill in the paths for your server:

```bash
cp .env.example .env
# Edit .env with your paths
```

The `.env` file is in `.gitignore` and will not be pushed.

## Experiments Overview

### bioGWAS Simulated Data (Scripts 00-03)

These experiments test LSEA on simulated GWAS data generated by
[bioGWAS](https://github.com/TohaRhymes/GWAS_simulator).
Simulations use 10,000 individuals with known causal pathways from MSigDB C2/KEGG.

| Script | Experiment | Runs | Description |
|--------|-----------|------|-------------|
| `00_create_universe.sh` | Universe generation | 1 | Create universe JSON from variants + gene annotations |
| `01_lsea_continuous.sh` | Continuous traits | 200 (50 iter x 4 pathway sizes) | Test LSEA power on continuous phenotype simulations |
| `02_lsea_binary.sh` | Binary traits | 200 (50 iter x 4 pathway sizes) | Test LSEA power on binary phenotype simulations |
| `03_lsea_sensitivity.sh` | Sensitivity (k) | 135 (15 k-values x 3 iter x 3 sizes) | Vary number of causal SNPs from pathway (k=1..15) |

**Pathway sizes:**
- `small` — ~20 genes
- `medium` — ~50 genes
- `big` — ~100 genes
- `random` — control (causal SNPs not in any pathway)

**Simulation parameters:**
- N = 10,000 individuals
- K = 30 total causal SNPs
- k = 15 causal SNPs from target pathway (except sensitivity experiment)
- Genotype data: 1000 Genomes EUR

### Pan-UK Biobank (Scripts 04-06)

These experiments apply LSEA to real GWAS data from the
[Pan-UK Biobank](https://pan.ukbb.broadinstitute.org/) project (139 phenotypes, MIS selection).

| Script | Experiment | Description |
|--------|-----------|-------------|
| `04_panukb_universes.sh` | Universe creation | Create 6 universes (one per gene set category) |
| `05_panukb_enrichment.sh` | Enrichment (Exp. 1) | Run LSEA on phenotypes x 6 gene set categories |
| `06_panukb_gwas_on_gwas.sh` | GWAS-on-GWAS (Exp. 2) | Use phenotype loci as "gene sets" for cross-trait enrichment |

**Gene set categories:**
| Short name | Source | Description |
|-----------|--------|-------------|
| `c2` | MSigDB C2 | KEGG pathways |
| `gte` | GTEx v8 | Tissue-specific gene expression |
| `bcm` | Literature | Blood cell marker genes |
| `go_bp` | MSigDB C5 | GO Biological Process |
| `go_cc` | MSigDB C5 | GO Cellular Component |
| `go_mf` | MSigDB C5 | GO Molecular Function |

## Common Parameters

| Parameter | bioGWAS value | Pan-UKB value | Description |
|-----------|--------------|---------------|-------------|
| `--clump_p1` | 7.2973e-9 | 7.479e-9 (0.05/6685228) | P-value threshold for lead SNPs (Bonferroni) |
| `--clump_p2` | 0.01 (default) | 0.01 (default) | Secondary clumping threshold |
| `--clump_r2` | 0.1 (default) | 0.1 (default) | LD r^2 threshold |
| `--clump_kb` | 500 (default) | 500 (default) | Physical distance for clumping (kb) |
| Interval | 500,000 bp | 500,000 bp | Universe interval size |

**Pan-UKB GWAS preprocessing:**

Pan-UKB summary statistics have `neglog10_pval_EUR` instead of p-values
and need normalization before LSEA. Use `preproc_tsv.py`:

```bash
python3 experiments/preproc_tsv.py INPUT.tsv.tsv OUTPUT.norm.tsv BFILE.bim
```

**Utility scripts:**
| Script | Description |
|--------|-------------|
| `preproc_tsv.py` | Normalize Pan-UKB GWAS summary statistics |
| `validate_single_runs.sh` | Run ONE test per experiment type and compare with existing results |
| `rerun_all_biogwas.sh` | Full re-run of all 535 bioGWAS experiments to a new directory |
| `compare_results.py` | Compare annotation_stats between old and new results |

## How to Reproduce

1. **Set up `.env`** with your server paths
2. **Run scripts in order** (00 must complete before 01-03; 04 before 05-06)
3. **Check results** against `../results/` directory

```bash
# Example: single test run
bash experiments/00_create_universe.sh
bash experiments/01_lsea_continuous.sh   # takes ~hours for 200 runs
```

## CLI Flag Reference

Old scripts used single-dash flags (e.g., `-input`, `-variants`).
Current LSEA uses standard `--long_flag` format. All scripts in this directory
use updated `--` flags. See mapping:

| Old flag | New flag | Short flag |
|----------|----------|------------|
| `-variants` | `--variants` | `-v` |
| `-features` | `--features` | `-ft` |
| `-interval` | `--interval` | `-i` |
| `-input` | `--input` | `-i` |
| `-universe` | `--universe` | `-u` |
| `-out` | `--out` | `-o` |
| `-plink_dir` | `--plink_dir` | `-pd` |
| `-bfile` | `--bfile` | `-bf` |
| `-column_names` | `--column_names` | `-cols` |
| `-p` | `--clump_p1` | `-c_p` |
